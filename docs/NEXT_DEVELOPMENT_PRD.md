## 0. 执行约定

1. **一个任务一个独立变更**。只有用户授权提交后，才按任务粒度提交，提交信息以任务编号开头（如 `S1-3: …`）；本轮不 commit、push 或发布。第 4 节保留任务定义，当前实施次序以第 5 节版本计划为准。
2. 每个任务完成后运行 `./scripts/build.sh`（`assembleDebug testDebugUnitTest lintDebug`，Kotlin 与 lint 警告即失败）。涉及界面或 WebView 的任务再跑对应设备测试和 `scripts/tests/*`。
3. Sol 负责可执行的构建、回归和证据，用户负责产品取舍与实际体验；缺设备时列出阻塞，不把全部技术验证转交用户。交付时写明“已自测 / 环境阻塞 / 待真机体验”的实际状态，不把未运行的检查写成通过。
4. 不得削弱安全不变量（第 3 节）。需要新增权限（尤其 `INTERNET`）的任务，只能在第 4 节标明的里程碑内进行，并先完成该里程碑的隔离设计。
5. 不做范围外重构；发现问题记入任务说明的“遗留”小节。
6. 新增依赖必须固定版本、确认存在于 Google Maven / Maven Central，并更新 `docs/DEPENDENCIES.md` 与 `licenses.txt` 生成输入。
7. 新增 UI 用户文案使用简体中文与 `res/values/strings.xml`。历史 core/data/formats 提示按 R-08 分类渐进迁移；不得为资源化向 core 注入 Android Context，也不批量替换历史存储值。

## 3. 不变量（任何任务不得违反）

1. 不声明 `READ/MANAGE_EXTERNAL_STORAGE`；文件只经系统选择器读取；**用户原文件永不被修改或删除**。`INTERNET` 只在 S6/S7 里程碑按隔离设计引入，本地图书阅读 WebView 永远不联网。
2. 正文 WebView：禁 file/content 访问、禁网络加载、禁弹窗与主 frame 导航；只有当前会话精确清单内的资源返回 200（内置字体为唯一的会话无关只读资源）；正文 iframe 不允许脚本，正文 CSP `script-src 'none'`；原生桥只认唯一 origin 与主 frame。
3. 导入原子性；`recover()` 只把无主目录移入 `trash/`。数据库升级非破坏、先做一致性备份。
4. 位置只存格式相关的稳定锚点；锚点失效时降级为“恢复到附近位置”并提示。
5. 阅读器浮层不改变渲染视图尺寸；破坏性操作二次确认并注明“设备上的原文件不会被删除”；状态用“图标 + 文字”；触控热区 ≥48dp。
6. 不复制 Readest AGPL 应用代码；vendor 文件只允许 PROVENANCE 记载、可重放的补丁。

### S4 · 数据安全：手动备份与恢复（产品 PRD 12.3，DATA-01…04）

> **实现状态：** 备份包/校验、一致性导出、启动时切库、界面与仅记录备份已实现；既定恢复保护问题已关闭，不自动重开全矩阵。“待重新关联文件”的重新关联导入仍未实现；本轮版本验收状态见当前交接。

- 范围：“完整备份”（图书副本、进度、书签、设置、固定版式缩放等单本状态、继续阅读状态）与“仅配置与记录”。经系统选择器导出为单文件（zip：`manifest.json` 含格式版本、文件清单与 SHA-256、生成时间、范围说明）。
- 导出：先估算大小与可用空间；导出期间暂停写入或用 SQLite 一致性备份；导出过程可取消并显示进度。
- 恢复：校验 → 预览（书数、大小、版本）→ 确认替换本地库（提示先备份当前库）→ 在暂存区完整恢复后整体切换；失败保留原库。高版本备份拒绝；低版本走迁移；缺文件的元数据标为“待重新关联文件”。
- 切换前置契约：停止接收导入/删除/新写入，关闭阅读会话并等待 closingScope 与串行写排空，关闭数据库，撤销资源会话并失效 EPUB/封面缓存后才切库。即使 R-05 延期，也必须实现最小切换屏障与故障测试；不能把暂缓重构理解为不需要生命周期钩子。
- 数据库与文件目录的切换需有持久化阶段记录，明确每一步崩溃后的续做/回滚；由 LibraryBootstrap 协调启动恢复。恢复暂存区须被普通 recover 清理识别为受保护事务资产，不能当无主目录丢入 trash。导出要冻结一致的数据库及文件清单/资源版本，或暂停删除、导入等相关写入，不能只快照数据库却导出已变化的文件。
- 恢复包按 SEC-05 / AT-15 验路径穿越、异常层级、压缩比/解压总量、单文件与条目数限额；全部输出限制在任务目录。旧包替换新库的预览须列出包中缺失、恢复后将被替换掉的文章/订阅等类型。
- 界面：设置“备份与恢复”、`Backup`、`RestorePreview` 画板；“卸载前请先导出备份”提示。
- 验收：备份 → 清除数据 → 恢复后，书目、进度、书签、设置逐字段一致；损坏/截断/高版本包被拒且原库不变。

### 5.3 跨版本契约与功能补齐

- **备份随每次数据能力扩展同步升级。** 0.5 当前书库 → 0.6 分类/字体/规则 → 0.7 主动保存的文章/版本/图片 → 0.8 订阅/分组/关系/管理状态 → 0.9 新格式页内位置/方向/缩放。每次都覆盖旧包迁移、字段往返和失败保护；这不是新增差分备份算法。普通 RSS 可清理缓存默认排除；Cookie/令牌/网站会话始终排除。仅记录恢复不宣称离线可读。
- **文章四种状态分别建模。** 正文质量、任务状态、资源离线程度、用户管理状态独立，以状态到文案真值表及 JVM 测试锁定；摘要、缺图、完整性未确认不得显示完整全文离线。实体身份与 feedID+GUID 分开，分享/RSS 复用，删除标记防止刷新复活；重新获取失败保留旧版与进度，成功后用户确认切换版本。0.7 开工前定下生产文章渲染协议和稳定 Locator，当前 ArticleSamplePublication 协议 1 只是参考，不能未经设计直接承诺其持久化兼容；文章搜索在 0.7 实现、0.8 复用。
- **清理以保留意图和引用关系为准。** 主动保存/收藏文章及被其他来源引用的必要资源不自动淘汰；清 RSS 缓存立即更新离线标识、保留身份和已读记录。删除分类不删书，删订阅不等于删文章。
- **网络边界单独审核。** 获取/交互 WebView 不暴露通用桥或本地书库，按 S6-0 独立进程/专用 WebView 数据目录隔离；提取器不能代替净化。DNS 解析后的地址与每次重定向重新校验，连接目标必须符合校验策略，防止地址变化绕过；限制协议、内网/回环、资源大小与超时。HTTP Feed 逐源明确允许，不全局降级。登录/验证由用户在真实网站处理，不绕过限制；外部打开不算抓取完成。
- **新增格式是完整闭环。** MOBI 保留旧 MOBI/混合 MOBI 可识别正文边界；PDF 原页/缩略图/跳页/缩放/页内位置；漫画自然排序、方向、长图按需解码/缩略图/坏图跳过。不能用纯文本提取冒充 PDF，也不能用可打开冒充可恢复。
- **设计补齐随对应版本交付。** 0.5 备份进度/恢复；0.6 字体管理/分类/TXT 规则；0.7 捕获任务/失败/辅助获取/会话/文章设置；0.8 HTTP 风险与网络策略。复用现有画板，缺少的先定交互。Sonnet 只接指定任务，当前下一项具体 UI 需求仍为“待指定”。

## 6. 主要风险

| 风险 | 应对 |
|---|---|
| WebView 版本差异导致字体缓存、`font-display` 或预载行为不同 | V-2 在 API 29 与当前设备各跑一遍；预载失败只影响速度不影响正确性 |
| 引入网络后误伤本地阅读的安全模型 | S6-0 先设计并评审；本地阅读 WebView 的拦截与 CSP 测试保持不变 |
| 备份包含私人阅读内容 | 沿用 PRD 默认不加密并在导出前明示；不含 Cookie/令牌；提前加密为新增范围，不重复确认现有基线 |
| 站点适配随网站改版失效 | 适配器版本化，失败分类可读，保留原链接 |
| MOBI/PDF 依赖许可 | 进入 S8/S9-7 前完成许可审查 |
