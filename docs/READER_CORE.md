# 阅读内核层：边界与维护决策

日期：2026-10-04。决策来源：用户询问是否单独维护阅读内核；本轮确定采用独立内核层，固定上游 JS 引擎版本，维护 Android 适配与排版配置，只保留必要的小幅补丁。后续用户明确要求拆解规则与渲染器、参考更多项目；本文件按该要求修订，完整 ADR 见 [CORE_ARCHITECTURE.md](CORE_ARCHITECTURE.md)。

## 维护什么

项目单独维护逻辑上的阅读内核层，让 Compose 界面、书库和数据库通过稳定接口使用它。先保持清晰包/接口边界；无需为满足“独立”立即拆出多个构建模块。

- 渲染后端：经固定 Readest/foliate、官方 foliate、Readium 和 EPUB.js 对比，首选 `readest/foliate-js@341dc63cda7ad26b31ada4ee905e40b5020da88a` 的独立 MIT paginator；理由是现成多视图连续滚动与 Range 定位，最终准入依赖实际运行/有界性/安全测试。仅复用该模块，不搬 Readest 应用；不跟踪 main，也不自行重写浏览器排版。
- Android 适配：WebView 生命周期、受控本地资源、字体加载、消息桥、安全策略、设备尺寸与系统缩放、暂停/恢复。
- 内容适配：将图书章节、TXT 段落索引和文章快照映射成引擎可读取的内容，保留各自身份与结构。
- 排版配置：独立实现且带版本的 Readest 行为规格、默认字体链、正文 CSS、布局参数和配置迁移；以固定版本源码和同设备样本为依据。
- 必要补丁：仅针对可复现的 Android 兼容、安全或定位问题，小幅修改并登记；优先回馈上游或在上游修复后移除。不能把大量应用逻辑塞入上游引擎。

## 接口边界

以下是目标契约，不声称所有接口已经实现。

| 边界 | 输入/输出 | 归属 |
| --- | --- | --- |
| 打开阅读会话 | 内容 ID、版本/快照 ID、格式、受控资源引用、初始 Locator、排版配置 | Android 适配层创建会话；引擎不读取应用数据库 |
| 加载内容/资源 | 章节或资源标识 → 有界正文/资源；错误、取消、资源状态 | 内容/资源仓库提供；引擎不能直接访问任意文件或网络 |
| 阅读操作 | 目录/位置跳转、前后页、模式与排版更新、暂停/关闭 | UI 调用会话接口，不直接调用 foliate 私有方法 |
| 阅读事件 | 稳定位置、目录、可用能力、加载阶段、失败、重排完成 | 引擎经适配层输出；业务层决定持久化和用户文案 |
| 定位 | 内容/版本、锚点类型、章节/段落/字符偏移、备用进度 | 项目 Locator 是持久化契约；CFI 可为一种载荷，不作为所有格式共同唯一位置 |
| 安全 | 受控 origin、资源白名单、最小消息协议、来源/会话/范围验证 | Android 适配与内容清洗共同负责；书内脚本不因引擎启用 JS 获得可信权限 |

书架分类、文章收藏/归档、RSS 更新和数据库事务留在业务层。PDF/漫画可以保留独立渲染后端，共享会话/进度上层接口；不强制把所有格式塞入同一流式 JS 内核。

## TXT 与文章不能共用一个简化字体结论

两类内容可以进入同一流式内核，但原始 DOM 和样式路径不同。

- Readest TXT 转换器使用 Arial 后接 generic sans-serif 的起始链；还包含 TXT 自己的段落规则。
- 剪藏/RSS 文章带系统 sans 字体栈与标题、图注、引用、代码等结构规则。
- Readest 会将 generic 字体项接到应用字体变量，再与默认字体、中文字体和正文样式共同级联。必须保留此顺序与覆盖开关，不能把正文全部强制设成一个字体来宣称一致。
- 默认手机正文设置、实际 CSS 字号、平台 textZoom、字体加载和每个字形的 fallback 分别核验。文章仍可按清洗 HTML + 本地资源存储，不因共用阅读内核就变成书架图书。

具体固定来源与差异见 [READEST_PARITY.md](READEST_PARITY.md)；字体文件、许可、哈希与覆盖范围见 [FONTS.md](FONTS.md)。

## 上游更新与补丁流程

1. 记录候选上游 commit、变更原因、许可证/依赖变化和受影响能力；保留已验证版本，不自动追踪分支。
2. 为问题建立原创或有授权的最小复现样本；明确是上游缺陷、Android 适配问题还是项目排版配置问题，补丁放在对应层。
3. 必要的上游改动以小补丁保存，逐项登记问题、基准 commit、修改文件、回归样本、上游 issue/PR（如有）与移除条件；不在 vendor 目录静默改代码。
4. 在候选版本运行固定样本：TXT/文章字体级联、EPUB/MOBI、分页/滚动、目录/脚注/图片、选词、中文混排、字体加载重排、缩放/旋转/前后台、位置恢复，以及恶意资源/消息桥/离线请求阻断。只对实际接入的能力报测试结果，未接入项保留待验证。
5. 与手机固定 Readest 基准进行严格正文对照。升级上游引擎不自动升级产品的排版验收基准；若要切换 Readest 基准版本，单独登记差异。
6. 检查 Locator、段落索引和配置版本兼容；需要迁移时保留旧数据并验证失败回退，不因升级使进度回到开头。
7. 独立审核通过后固定新 commit、依赖和校验值，更新补丁清单与测试报告；失败回退旧版本。上游吸收补丁后删除重复补丁并重跑关联用例。

## 来源与许可分开登记

| 来源 | 边界 |
| --- | --- |
| 固定 Readest foliate-js fork | 已核根 LICENSE 为 MIT；保留版权/许可，实际引入文件和第三方依赖仍逐项登记。[固定许可](https://github.com/readest/foliate-js/blob/341dc63cda7ad26b31ada4ee905e40b5020da88a/LICENSE) |
| Readest 应用和排版实现 | 应用源码为 AGPL；本项目当前研究其行为并独立实现规则，不直接复制其 CSS/TS。需要复用时先形成具体来源、修改和发行义务清单，不能将其混标为 MIT。[固定许可](https://github.com/readest/readest/blob/8a56831af61841175b49cc2740bffcde57b470b0/LICENSE) |
| 字体文件 | 已取得的 Roboto/Bitter/LXGW 二进制按各自 OFL-1.1 分发，随包保留版权和许可；字体许可不决定应用许可，也不因 npm 顶层元数据变成 MIT。固定来源见 FONTS_MANIFEST.json |
| 本项目适配与配置 | 自行实现并记录来源参考；不得仅因依赖 MIT 内核就声称其他来源同为 MIT。整体发行许可仍单独确定 |

以上描述起始基线 `237d478`。本阶段已真实接入固定paginator并移除旧32块HTML载体。已获浏览器与原生运行证据；两项晚修已获关闭证据，产品hash已冻结，最终冻结版本11项真机复验已通过，具体能力以验证报告为准。
