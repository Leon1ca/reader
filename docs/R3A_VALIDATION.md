# R3A 长章节闭环验证

2026-10-05。阶段3包含长章节R3A及固定版式R3B；本文只记录R3A，R3B完成前阶段3仍为进行中。

## 变更及身份

长章节通过流式解析和有界批处理生成可随机读取的物理parts，逻辑spine与UTF16位置仍是持久身份。普通长段落、代理对切点、有序/逆序列表续编号、章节fragment映射保持原文；复杂超限rowspan明确拒绝。原始树的结构选择器用有界拓扑及同权重标记保留，不在每个物理part上重新计算原始nth/兄弟语义。每章规则及共享CSS资源分别编译，避免影响小章节。

缓存将逻辑sourceRevision与renderRevision分离，旧schema1只读兼容；施工版本style3通过生产Factory重建不可变derived-parts2-style4，完整源SHA、章节索引和canonical bytes校验、fsync后发布。旧缓存和原件保留，失败回退与取消清理均有验证。

可信host只缓存完成加载的canonical索引，最终Ready要求所有活动文档完成且已校验。恢复已经加载的同一主章Range使用公开scrollToAnchor，避免重复完整导航等待额外前邻；真正跨章导航和必要前邻加载保持。命令12秒/用例15秒及低内存设备48MiB堆限制均未增加。

## 失败保留与验收边界

所有中间失败日志保留在私有chatwork，未覆盖或改称偶发：selectors曾API29导入OOM；repair后导入通过但重排canonical mismatch，定向还出现初读超时；ready-cache仍anchorGoTo超时。本轮相同低内存/超时限制下原用例及完整API29通过。

分段加载旧host→新host真实对照复现并关闭早期索引缓存缺陷；同主章旧重复goTo→新Range恢复对照复现并关闭冗余前载阻断。先前API29日志phase表示命令预算耗尽时等待阶段，不据此宣称某个promise单独死锁12秒。桌面旧cache重建/CSSOM与失败取消已实证，桌面缺Android目录fsync不能冒充成功native发布；nativeFactory升级case和生产旧QA路径分别补此边界。
