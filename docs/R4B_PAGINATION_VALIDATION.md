# R4-B 分页、可见源范围与末页确认验证

2026-10-05。基线搜索提交 `ff7fd26c858205be4e4ae578a308863567fe841f`。

本文件仅验收分页模型、当前页书签、几何末页与显式读完闭环。目录及搜索结果的估算页码接入是下一增量；完整 R4-B、R4-C/D、正式 UI 和 R6 均不能据此标为完成。

## 行为与边界

- 同一已验证 Position 携带源版本、当前位置、真实可见文字半开区间、独立元素、合法空段/逻辑 EOF 点和可见固定页。原生源映射后再次校验会话与位置序号，过期结果不发布。
- 可见文字区间保留隐藏字符间的空隙；技术分段末端不能冒充下一段首字。相同字符偏移的不同图片元素仍是不同书签。
- 页码采用真实 iframe 分页几何。布局、字体资源、平台文字缩放与格式规则决定全局签名；单段实际字体及书写方向另有签名。跨双栏章节不会把主视图的页数误分配给旁边章节。
- 未测章节与连续滚动累计页数明确为估算。零字符图片页不会污染文字密度；未测段的 1200 字符/页是估算种子，不是精确排版或性能结果。章节剩余页按真实目录边界计算。
- 几何末页允许当前位置比例不足 100%，也允许放大后只显示固定版式末页的一部分。提示不自动写入读完状态；明确确认才标记读完，撤销后恢复继续阅读。未答复提示可穿过重排，明确继续后不会因重排重复询问，离开再进入末页可再次提示。
- 协议 1/2 的密集区间和元素采用有界紧凑传输，保留精确成员关系。原始消息上限 64 Ki UTF16，区间字节预算 40 KiB、区间与元素各最多 16K；格式、溢出、源归属和重复均检查。消息超限明确报错，不静默丢弃定位。

独立审核直接消费真实资产和编译类：

- 横排、竖排两方向与 RTL/LTR；双栏跨不等长章节的实际样本归属、可见源字形、稳定签名；实际末页比例不足 1；滚动估算。
