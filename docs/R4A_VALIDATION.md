# R4-A 状态与存储验证

2026-10-05，最终候选 `r4a-prefs-compat`。R4-A 子阶段通过，R4 整阶段仍在开发；后续搜索、分页尾部、链接/注释/选文及导入管理须另行验收。

## 实现

schema5 增加继续阅读隐藏标记与可空 EPUB 字数；完成、隐藏、当前位置、最远进度互相独立。只有真实 Ready 后接受有效位置才记录阅读时间并取消隐藏，准备或打开失败不会记录阅读。详情采用轻量元信息，未统计字数显示未知、真实零显示零。书架投影支持中文排序、查询、格式筛选及筛选后选择收敛。生产界面消费 ControllerFactory 与 typed actions，快照准备默认后台读取，取消或失败释放已打开来源。

首次升级仅在新排序键缺失时迁移旧 ui.sort 中文值，已有新设置优先，旧偏好文件保留。全局背景与翻页模式仍只清除对应单书覆盖。Controller 永久关闭撤销动作；界面配置重建只解绑稳定 Surface。
